# C-前端交互设计

> 完整交互/视觉/i18n 以设计原型 `cms/CMS 客户管理系统.dc.html` 为 SSOT。本文摘录结构与映射。

## 1. 视觉规范
- 主色：阿里橙 `#FF6A00`（hover `#D94C00`）；辅色蓝 `#2B5FD9`、绿 `#0E9F85`、红 `#C7361B`。
- 字体：Plus Jakarta Sans + Noto Sans SC。
- 圆角 12-22px；卡片白底 `#FFF` + 细边 `#EBEDF2` + 柔影。
- 头像 8 色渐变色块（按 avatar 索引）。

## 2. 页面与路由
| 路由 | 页面 | 角色 |
|------|------|------|
| /login | 登录/注册（tab） | 游客 |
| /home | 首页：下游概览/指标/升级进度/上级/快捷操作 | 客户 |
| /customers | 客户网络（列表/树形、筛选、搜索、面包屑） | 管理员/客户 |
| /customers/:id | 客户详情 + 管理员操作 | 管理员/客户 |
| /stats | 统计报表（KPI/7日柱状/级别分布/最近） | 管理员 |
| /messages | 消息（好友/群组 tab + 会话列表） | 客户 |
| /messages/dm/:id /group/:id | 聊天线程 | 客户 |
| /me | 我的：资料/头像/语言/登出 | 全部 |
| /config | 系统配置（maxLevel 只读 + 指标/门槛） | 管理员 |

## 3. 底部导航
- 客户：首页 / 客户 / 消息 / 我的
- 管理员：报表 / 客户 / 配置 / 我的
- 桌面端(≥900px)：左侧栏导航；移动端：底部 tab。

## 4. 关键交互
- **完善资料 nag**：登录后若 profileDone=false → 弹窗（立即完善/暂不填写），暂不填写可关，但每次登录再弹。
- **拓展客户**：输入 11 位 ID 弹窗 → 成功 toast + 可能升级提示。
- **树形浏览**：点节点深入，面包屑可回退；叶子节点进详情。
- **聊天**：底部输入框，群禁言时输入框置灰显示"群主已开启全员禁言"。
- **语言切换**：我的页切换 zh/en，即时生效，存 localStorage。

## 5. i18n
直接迁移设计原型 `T` 字典（zh/en 两套完整文案）。模板变量 `{n}`/`{l}` 用工具函数替换。

## 6. 响应式
移动优先，断点 900px。详情/线程页移动端带顶部返回栏。
