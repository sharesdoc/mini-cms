## 2. 需求覆盖（CMS-需求文档.md 逐条）
| 需求域 | 状态 | 实现要点 |
|--------|------|----------|
| 注册/登录(AUTH) | ✅ | 用户名+密码、密码≥6+二次确认、11 位随机 ID、手机号默认提示、管理员口令由环境变量提供 |
| 完善资料(PROF) | ✅ | 姓名/身份证/电话/住址、首次登录 nag 反复提示直至完善、头像(8 色) |
| 客户层级(LVL) | ✅ | 硬上限 3 级、指标-1、自动升级、管理员临时调指标、单一上级、跨级可见性禁止 |
| 客户网络(NET) | ✅ | 管理员全量+级别筛选+树形逐级+面包屑后退+搜索、客户仅自己下游、详情 |
| 管理员(ADM) | ✅ | 伪删除、禁用/激活、统计报表(总数/今日/本周/7日/级别分布/最近) |
| 即时通讯(IM) | ✅ | 按 ID 加好友、建群、群主加删成员/禁言、纯文本单聊群聊、禁言非群主拒发 |
| 非功能(NFR) | ✅ | 移动优先响应式、阿里橙、中英文切换、前后端分离 |

- **安全闸门**：鉴权拦截、越权 403、参数化 SQL（防注入）、BCrypt 密码、敏感字段脱敏、admin 口令不落库。

## 4. 迭代中修复的真实缺陷（6 个）
1. 🟡 **errLevel 阻断新用户拓展升级**（核心机制）— 需求↔设计冲突，按需求移除 level 闸门。
2. 🟡 **好友/群组接口 PII 泄漏**（隐私）— 引入 PublicUserVO 脱敏。
3. 🟡 **并发抢同一目标竞态**（并发正确性）— 原子 claimTarget + 失败退还指标。
4. 🟡 **home.parent 上级 PII 泄漏**（隐私，上轮遗漏）— 同样脱敏。
5. 🟡 **生产 CORS 预检被鉴权拦截**（上线即坏）— 放行 OPTIONS。
6. 🟡 **并发同用户名注册 500**（健壮性）— DuplicateKey→40901。
另：拓展指标扣减原子化、代码冗余清理、favicon、前端测试补齐。

## 5. 启动方式
```bash
# 数据库（任意 MySQL 8；凭据通过环境变量提供）
mysql -uroot -p < dbs/cms-database.sql
# 后端
cd svc && mvn -DskipTests spring-boot:run        # :8080
# 前端
cd web && npm install && npm run dev              # :5173
# 管理员登录口令由 CMS_ADMIN_PASSWORD 提供；不要把它提交到仓库
```
